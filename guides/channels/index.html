AI 中转站渠道分组科普：Max / 逆向 / Kiro / 官转都是什么

同样是卖 Claude、GPT 的调用额度，不同中转站背后接的其实是完全不同的货源。价格能差出几十倍，根本原因就在于渠道不同。搞清楚下面这 8 种渠道分组，你就能大致判断一个便宜价格背后到底是什么在支撑。

官转 / 直连

风险：低

价格最高

中转站自己持有官方 API Key，请求原样转发到 Anthropic、OpenAI、Google 的官方端点，行为、字段、限流规则和官方完全一致，功能也最全。因为走的是官方计费口径，价格通常也是所有渠道里最贵的一档。

适合谁：适合放在生产环境、对响应稳定性和字段兼容性要求高的场景。

Max / Pro 订阅套餐

风险：中

中等偏低

中转站批量购买官方的订阅套餐（比如 Claude Max、Pro 这类月费 $200 左右的档位），组一个号池，再按 token 拆分转卖给用户。底层账号是正版订阅，本身不算灰产，但会撞上官方给个人订阅设置的频率上限，也存在多人共用一个额度池的情况；有些站点只能接官方自带的客户端（比如只能用官方 Claude Code），第三方工具接不进去。

适合谁：适合预算有限、能接受偶尔限流、且用的工具刚好被支持的用户。

Claude Code / Codex 专属通道

风险：低

视订阅而定

这类通道只认官方 CLI 客户端发出的请求（靠 User-Agent 之类的特征识别），Cursor、Cline、Continue 等第三方编辑器接进去大概率报错或直接拒绝。渠道本身风险不高，问题在于使用场景被卡死。

适合谁：只用官方命令行工具、不折腾第三方编辑器插件的人。

Vertex AI / AWS Bedrock

风险：中

中等

通过 Google Cloud 的 Vertex AI 或 AWS 的 Bedrock 服务间接调用 Claude，底层模型确实是 Claude，但走的是云厂商自己的请求结构，字段、返回格式和官方 Anthropic API 有细节出入，个别边缘参数或元数据可能对不齐。

适合谁：能接受轻微字段差异、看重价格比纯官转低一些的用户。

Kiro

风险：中

极低价

薅的是 Amazon 旗下 Kiro IDE 公测期间放出的免费 Claude 额度，底层实际上还是走 AWS Bedrock 的 Claude。价格便宜到几乎不要钱，但这类额度完全依赖 Amazon 自己的推广策略，公测结束、额度收紧或者规则突然变化都可能发生，可用性说没就没。

适合谁：纯粹图便宜、能接受额度随时被收紧甚至下架的尝鲜用户。

反重力 / Antigravity

风险：中

极低价

同样是薅厂商放出的免费额度，只不过对象换成了 Google 的 AI 编程 IDE 附带的免费 Gemini 额度。逻辑和 Kiro 几乎一样：便宜是因为在吃平台推广期的红利，风险也在于这个红利随时可能被收回。

适合谁：只用 Gemini、对价格极度敏感、能接受随时失效的用户。

逆向

风险：高

便宜

不走官方付费 API，而是逆向工程网页版（Claude.ai、ChatGPT 网页端）的私有通信协议，用自动化脚本模拟登录一个 Pro 账号在网页上跟模型对话，再把结果包装成 API 返回给你。因为完全绕开了官方计费，价格能压得很低，但 stop_reason、流式返回格式、上下文长度限制等细节都和官方 API 有出入，遇到官方页面改版随时可能失效，长对话也更容易被莫名截断或悄悄换成更弱的模型。

适合谁：只是想低成本试试效果、能接受不稳定和随时中断的用户，不建议用于正式项目。

按次计费

风险：高

看着极低

不按 token 计费，而是「¥X/请求」或者「N 次套餐」的形式卖。单价看上去很诱人，但几乎每个按次套餐都隐含了上下文长度或输出长度的限制——超出部分要么截断、要么额外收费。长会话、长文档处理这类场景很容易在不知不觉中触发隐形成本，实际单价可能比看起来贵得多。

适合谁：只做短平快的单轮问答、不涉及长上下文的轻量使用者。

选渠道之前，记住这几句

价格越低的渠道分组（Kiro、反重力、逆向、按次计费），出现掉包、悄悄降级、临时不可用的概率也明显更高——这不是危言耸听，而是这些渠道本身的机制决定的：要么依赖厂商随时可能收紧的推广额度，要么绕开官方走的是不受保护的私有协议。

如果你追求的是稳定可靠，优先选官转或 Max/Pro 订阅这类底层货源正规的渠道；如果你更在意价格、能接受偶尔翻车，再考虑低价分组，但要有心理预期。

不管选哪种渠道，第一次充值建议先小额测试几天，确认响应质量和稳定性符合预期后再加大投入。
